# 拼音与校核说明 · 2026-10-16

用户确认采用现代普通话与教材常用读法，没有额外指定比赛读音。阅读页可开关带调拼音，覆盖现有200篇的题名、作者说明、小序与1460行正文，诗词原文不变。

## 数据与校核方法

1. `pinyin-pro@3.29.5`与`@pinyin-pro/data@1.3.1`扩充词典离线生成初稿。词典只在生成时使用，客户端只加载约154KB的静态逐字读音数据。
2. 检查题名、作者专名、常见多音字在原句中的用法，参考第二转换词典的分歧候选辅助定位；两个程序相同也不作为读音正确的证明。按句意修订“为、朝、还、重、行、系、着、应”等容易按现代常见词误分词的场景。
3. `src/data/pinyin-overrides.json`保留288条定点修订/确认规则，匹配330处，含触发原句、篇目范围、读音、原因和依据。匹配次数不等于修改字符数，已正确的关键读法也会固定为规则，以防后续词典变化。常用字音的语义选择是本项目校核判断；特殊诗句另参考注本，不能将所有规则都宣称为第三方逐字审定。
4. 已检索的特殊读法有《击鼓》的镗、于嗟、成说，《淇奥》的奥、会弁、重较，《七月》的于貉、亨葵、重穋，《上邪》的邪、雨雪、衰，以及《将进酒》的两个“将”。文献存在异读时，在对应阅读页“注音规则与本篇易读错字”中说明采用的解释并附来源。具体链接保存在修订数据中。

这是一份经词典生成并重点校核的学习注音，未宣称200篇所有汉字都经过语言学专家逐字校审。古诗通假、古今异读及注本释义可能不同，已发现的差异保留说明；若比赛以后给出指定读音，可按原句独立修订。不会为了押韵自行更改普通话读音。

## 标注约定

- 拼音采用字典本调；“一、不”明确标为yī、bù，连续三声不在书面上改调，轻声词按词典语义处理。实际朗读仍有语流变调。
- 标点、空格、书名号不注音；异体字和罕用字保留原字，不改出题材料。
- 全文模式逐字上注；遮字/首字模式中，被遮住的字同时没有拼音，点按揭晓才一起显示。
- 开关默认关闭，记住当前浏览器选择；不加入学习进度，也不改动已验证的账号同步协议。

## 复现与验证

```powershell
npm ci
npm run prepare:pinyin
npm run check:pinyin
npm test
npm run build
npm run test:sites
```

生成器输出`src/data/pinyin.json`，并将逐句校核文本、所有多音字候选和漏注列表写到被忽略的`tmp/pinyin-audit/`。有未命中的修订锚点、位置冲突或汉字漏注时立即报错。构建会重新生成并比较静态文件，以防题库更新后拼音索引错位。

29项数据/逻辑/SQL测试通过（其中新增3项拼音测试，含24个特殊场景断言），4项模板发布测试通过。新增检查覆盖200篇每一行的字符对齐、汉字无漏注、标点无拼音、原文哈希与关键字音，以及遮字时的隐藏逻辑。

独立Playwright浏览器已验证：默认关闭、开关、刷新记住选择、同字不同音、遮字/首字/揭晓/重新遮住；在320、390、834、1440像素宽度分别打开10篇包含长题名、长诗、小序和现代诗的作品，无水平溢出。古诗桌面和现代诗手机页axe WCAG A/AA扫描0项违规，无未捕获页面异常。截图：`docs/design/pinyin-desktop.png`和`docs/design/pinyin-mobile.png`。
