# 理解与注释 · 2026-10-16

用户要求每一篇有必要注释，以理解帮助背诵，并选择“重点理解版”。现有200条指定材料全部具备独立大意、1135条词句说明与724个按原文顺序排列的背诵锚点，不用通用模板代替作品内容。

## 内容与来源

- 逐篇读取`src/data/poems.json`，按首句区分同名异作；长篇、组诗和现代诗分别整理。概要与背诵路线以本站措辞写作，词义和典故参照公开译注重点核对，不复制整篇译文或赏析。
- 每篇至少一个可点击参考链接，保存在`src/data/annotations/references.json`。多数古诗词链接至古文岛（原古诗文网）的对应原文／译注页；另参考识典古籍、教育部网站所载材料、人教社教学资料、央广网、大学教学案例及现代诗研究资料。链接供查阅与比较，不意味着网站认定这些来源的每种解释都是统一标准。
- 重点核对了《七月》的纪月、流火与农事词，《离骚》家世、香草、美人的不同解释，《赠白马王彪》的序文与生离死别，《正气歌》的守节典故，《暗香》《疏影》的咏梅典故，以及两首《燕歌行》、不同《长歌行》和多首同词牌作品的区别。
- 现代诗侧重意象、对照、视角与情感推进，使用“可理解为”等措辞区分解释与字典定义；没有把作者人生传闻当作诗中明确情节，也不把某种象征解读说成唯一标准答案。
- 这些是经资料参照与重点核对的学习注释，不宣称所有词句均经古典文学专家逐字审定。比赛如发布专门解释，需据其要求复核。

## 指定材料差异

1. 《九歌·山鬼》这一条在材料中后接《国殇》片段，注释分别说明山鬼赴约与国殇战场，不混同叙述者；不额外补入材料未收录的末句。
2. 第56篇《山中》在指定PDF印刷第15页署王勃，文字却是“荆溪白石出…”的通行王维诗。已直接核对PDF该页，并在注释中说明，不更改现有署名及作者题。读者可向比赛方核实。
3. 《赠秀才入军》不同选本组诗编号有差异，按“息徒兰圃”匹配。《菩萨蛮·平林漠漠》保留指定材料的无名氏署名并提示常见归属争议。
4. 《赠白马王彪》和《定风波》的指定数据中含序文，注释提醒其作用；《寻梦者》指定文字“旱海”与常见“瀚海”有异，保留原字并解释。

材料提示只影响注释，不改`poems.json`、既有拼音数据、题库答案、间隔复习算法、邮箱登录与云同步协议。

## 数据与工程校验

```powershell
npm run check:notes
npm test
npm run build

```

`check:notes`核对200篇唯一ID、正文源哈希、每条引用是否实际出现、724个路线锚点是否按原文顺序排列、长篇内容充分度及逐篇HTTPS参考链接。正文哈希对解析后的JSON计算，不受Windows与Linux换行差异影响。

新增3项测试覆盖完整内容、易混篇目／典故与材料差异，以及错篇、虚构词句、倒序路线和非HTTPS来源的拒绝。32项主测试、4项Sites打包测试和生产构建均通过。重新生成本地字体后，注释涉及的汉字在衬线与无衬线字体中均无缺字。静态注释作为五组JSON按需加载，初始页面不请求注释；成功结果在本次打开期间缓存，网络失败会清除失败缓存以便重试。

## 浏览器验证

使用已获用户授权的独立Playwright浏览器，创建访客上下文，不操作真实账号。

- 桌面逐篇打开200篇，实测显示1135条词句与724个思路锚点，无未捕获页面异常。
- 默认收起时无注释正文、无注释网络请求；首次展开仅请求当前分组和参考表，同组再次展开使用缓存。
- 点按“陈王”等词句后收起面板、定位并聚焦正确原文行；遮字、首字、全文切换都卸载已展开内容；在遮字状态主动展开再定位，也不会揭晓任何被遮住的行。
- 320、390、834、1440像素各打开13种长篇、组诗、现代诗与词的注释状态，无页面水平溢出。
- 手机大字号加拼音可与注释共同使用，材料提示与参考链接可访问；交互前后学习状态不变。
- 人为中断注释JSON请求，错误提示出现且原文仍可读；解除拦截后点击重新加载，成功恢复。
- 桌面古诗、手机现代诗、手机大字号＋拼音三种展开状态，axe的WCAG2 A/AA、2.1 AA与2.2 AA扫描均0项违规。这不等于完整无障碍合规或真实手机硬件测试。
