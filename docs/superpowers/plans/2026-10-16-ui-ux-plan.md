# 温故 UI 与 UX Implementation Plan

> **For agentic workers:** Use superpowers:executing-plans inline in the authorized existing checkout. No delegation is needed.

**Goal:** 在现有风格内改善首页、目录、阅读、抢答之间的完整学习流程。

**Architecture:** 现有 React 组件渐进修改；App持有目录浏览上下文，Reader持有本机字号，原有学习与同步数据模块保持不变。CSS新增独立优化文件，避免继续堆叠基础样式。

**Tech Stack:** React19、现有Phosphor图标、原生CSS、已授权Playwright CLI及现有axe-core。

**Spec:** ../specs/2026-10-16-ui-ux-design.md

## Global Constraints
- 保持已批准米白／松绿风格；不新增依赖。
- 保持200篇原文、拼音数据、评分与云同步协议。
- 偏好存储失败不能阻断阅读，输入与按钮可用键盘操作。
- 320像素无横向页面溢出；减少动态效果时关闭动效。

## Review Focus
- 手机吸顶工具不能占据大半屏幕或挡住聚焦内容。
- 搜索筛选返回、加载更多、切换账号不能产生旧上下文误导。
- 大字号和带调拼音、现代诗长句应一起验证。
- Space不能干扰输入框、组合输入和其他操作按钮。
- 超时／揭晓／结束本轮之间不能重复记题或制造未作答记录。
