# 温故 · 诗词备赛

用户已确认融合设计：`exec-022269d2-e80a-4184-b1a5-5fea376ee507.png`。

## 使用目标
为11月上半月院级抢答诗词比赛准备，覆盖学校PDF的162篇诗和38篇词，包括现代诗。个人使用，适配手机与电脑，GitHub Pages托管。

## 界面与流程
米白背景、墨绿主色、陶土橙辅助色；宋体诗文、无衬线控件。桌面侧栏、手机底栏。首页保留已确认的每日安排和继续背诵区域。导航：今日计划、全部篇目、抢答训练、错句复习。

读原文 → 全文/遮字/首字提示 → 自评掌握 → 到期复习；练习时支持上下句、挖空、作者篇名，限时或不限时，逐字反馈，答错自动加入错句，查看提示不能计为独立答对。打字时间标为作答用时，另提供先抢答再揭晓自评模式。

## 数据与存储
结构化题库带类别、标题、作者、全文、PDF物理页和印刷页。抽取跨页连续原文，保留小序但不以小序出题；异常字符核对原页。附带原始PDF用于查看。所有进度初始为零，不把设计示例当作真实记录。

浏览器本地保存学习记录、错句、答题历史、每日目标。导出/导入JSON备份；导入先验证，错误不覆盖现有记录。存储不可用时提示当前会话有效。无账号、无自动跨设备同步。

复习采用透明的递增间隔1/3/7/14天，记不清回到1天；不宣称完整FSRS。每日优先到期复习，再新学，最后抢答。比赛时间保持“11月上半月”，不虚构精确日期。

## 交付与验证
React + Vite静态应用，沿用Product Design桌面模板，构建输出dist/client，配置相对基础路径以支持GitHub项目子目录。真实测试题库数量/完整性、答案归一化、评分、复习日期、备份校验，浏览器验证完整学习/抢答/错句闭环、刷新保存、手机布局和键盘操作。GitHub Actions自动构建发布Pages；线上核验页面、资源、题库与PDF链接。
