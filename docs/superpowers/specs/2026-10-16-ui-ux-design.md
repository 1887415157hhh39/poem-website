# 温故 UI 与 UX 优化

用户要求进一步增强整体 UI 与 UX，随后选择“整体一起提升”，优先兼顾手机。沿用已批准的米白、松绿、宋体诗文与桌面侧栏／手机底栏；此次是现有产品的渐进优化，不重建产品和数据协议。

用户明确调用ui-ux-pro-max技能。设计token与组件状态按该技能落地：4/8/12/16/24/32像素间距、6像素控件与8像素面板圆角；主文墨绿、次级文字深灰绿、浅灰绿表面；保留现有自托管中文宋体与黑体配对。触控44像素起，输入16像素起，选择／悬停／聚焦／禁用／空／错误状态分别可辨；不为已有品牌另换字体方案。

## 当前页面证据

2026-10-16，独立 Playwright 新建访客环境，实拍首页、目录、阅读、训练设置、错句空状态，桌面1440×1024及手机390×844。原始截图在被忽略的`output/playwright/ui-ux-before/`。

1. 首页：风格统一，但手机开始按钮在632像素附近，进度接近底栏。优先提供当日进度和直接入口。
2. 目录：搜索内容被截断，手机无匹配诗句预览；返回原文后搜索筛选被重置。保留浏览上下文，清空与重置可恢复结果。
3. 阅读：长句可能仅一两个字换行；长篇控制栏会滚走。固定阅读工具、提供三档字号、按分句换行，并保留遮字与拼音的同步隐藏。
4. 训练：手机设置的开始按钮在首屏之外；计时只有小数字，题目进度不能区分已完成与当前。明确本轮配置、倒计时余量、各题结果及结束反馈。
5. 错句：已有空状态和操作入口，保留；训练反馈增加回原文的衔接。

截图能证明布局与层次，不能证明键盘、数据写入或无障碍合规；后续需独立交互验证。

## 方案选择

仅换配色不能消除上述操作阻碍；全面换版会偏离已批准视觉。采用针对学习流程的整体精修：保持页面和导航结构，调整组件层次与响应式布局，加入必要的阅读偏好和明确的状态反馈。

## 行为与边界

- 首页新增当日完成数、计划进度、按到期／新学／完成状态变化的行动按钮。原有三类任务保留，移动端压缩非操作性留白。
- 目录查询、分类、状态和已加载数量在页面间保留，返回目录恢复行位置；切换账号清空浏览上下文。搜索结果展示真正命中的正文，提供清除输入、重置筛选、无结果恢复。
- 阅读控制栏吸顶；全文／遮字／首字提示与拼音均可随时切换；提供小／标准／大字号并本机保存。古诗按标点分句成组换行，现代诗保留原始行序。已揭晓行可一键重新遮住。
- 训练设置提供本轮概要和清晰开始入口；题中显示已完成数量、每题对错状态、剩余时间与进度条。抢答键盘 Space 可在按钮聚焦时正常停表；输入模式不劫持空格和中文组合输入。
- 本轮结束可在当前题已提交后查看已完成题的结果，未提交题不虚构记录；下一题保留即时反馈，结果页可去错句复习。必要的状态焦点跟随页面，计时不反复向读屏播报。
- 原始200篇、拼音源数据、评分与间隔复习算法、邮箱认证和云同步协议不改。新增字号只保存在本机，不同步为学习状态。
- 不新增依赖，不加入装饰性重动画，尊重减少动态效果偏好，触控目标至少44像素，输入字体至少16像素，支持320像素宽度。

## 验收

真实浏览器验证：首页开始入口与状态；搜索正文、组合筛选、空结果、返回位置；三档字号、带拼音长篇、遮字／首字／揭晓／重新遮住；抢答、键盘、输入、超时、提示、错句、结束及汇总；320／390／834／1440像素无页面水平溢出，关键页面 axe 扫描、减少动态效果与键盘焦点。运行已有全部测试与构建后按已授权 GitHub Pages 路径发布并复查正式网址。
