# 诗词拼音

用户要求给现有200篇诗词加准确拼音，已明确没有比赛另行指定的读音，采用现代普通话与教材常用读法。

沿用现有阅读页，增加“显示拼音”开关，默认关闭；开启后题名、作者、正文及展开的小序逐字上注带声调拼音。视图偏好保存在本机，不改变学习记录与既有云同步协议。阅读界面自动换行，手机可用。正文、标点、出题与评分保持原始PDF数据。

可选方案：运行时自动转换实现快但难保证古诗多音字；只注生僻字阅读清爽但不能满足全文查音；采用完整静态逐字注音并结合逐篇读音修订，避免转换词典进入浏览器。选择第三种。

离线构建用开源拼音词典生成初稿，按篇和原句校正多音字、通假字、语气字及人名地名，保存修订依据与争议说明。不能仅凭押韵擅改现代读音，不宣称机器结果全部经权威逐字校审。审校说明区区分生成数据、重点校核与有依据的特殊读法。

显示层依据原始字符位置取拼音；遮字/首字模式下隐藏字符及其拼音，仅揭晓时一起显示，不从拼音生成器猜测遮罩文本。拼音通过HTML ruby展示，辅助注音对屏幕阅读器隐藏以免重复。长句按字换行，汉字与拼音始终同组。

验证：200篇全部覆盖、Unicode字符位置与拼音长度一致、汉字无漏注、标点不注音、修订锚点存在且无冲突、关键特殊读音回归；全部既有测试/构建/模板测试；实际浏览器全文、遮字、首字、逐行揭晓、刷新偏好、手机布局和无障碍扫描；GitHub Pages发布与线上检查。
